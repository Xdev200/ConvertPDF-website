# ConvertPDF — marketing website

3D animated Next.js site for **ConvertPDF** (iPhone, iPad, Mac).

- Home with Three.js / React Three Fiber hero
- Privacy Policy, Terms of Use, Support (App Store Connect URLs)
- 14 locales (`en`, `hi`, `ar`, `de`, `es`, `fr`, `id`, `it`, `ja`, `ko`, `pt`, `vi`, `zh`, `zh-TW`)
- Brand red `#E31E24`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

Privacy / Terms / Support paths: `/en/privacy`, `/en/terms`, `/en/support` (and other locales).
